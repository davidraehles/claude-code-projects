# Image Assets for Go, Cart! - Required Images

This document lists all required image assets for optimal SEO and branding. All images should be optimized and provided in WebP format when possible.

## Required Assets

### Favicon and App Icons
- **favicon-16x16.png** - 16x16px, PNG
- **favicon-32x32.png** - 32x32px, PNG
- **favicon-96x96.png** - 96x96px, PNG (for shortcuts)
- **apple-touch-icon.png** - 180x180px, PNG (iOS home screen)
- **android-chrome-192x192.png** - 192x192px, PNG (Android home screen)
- **android-chrome-512x512.png** - 512x512px, PNG (Android splash screen)

### Social Media Cards
- **og-image.png** - 1200x630px, PNG
  - Purpose: Open Graph / Facebook sharing
  - Content: Go, Cart! logo, tagline, appetizing food imagery
  - Brand colors: Coral (#E85A4F), Navy (#1A1A2E), Mint (#7EC8A3)

- **og-image-square.png** - 1200x1200px, PNG
  - Purpose: Square format for some social platforms
  - Content: Go, Cart! logo centered

- **twitter-card.png** - 1200x600px, PNG
  - Purpose: Twitter/X card image
  - Content: Similar to og-image with Twitter-optimized dimensions

### Logo Files
- **logo.svg** - Primary vector logo (scalable)
- **logo-light.svg** - Logo for dark backgrounds
- **logo-dark.svg** - Logo for light backgrounds
- **logo-icon.svg** - Icon-only version (no text)

## Design Guidelines

### Brand Colors
- Primary Coral: #E85A4F
- Deep Navy: #1A1A2E
- Mint/Sage: #7EC8A3
- Neutral Background: #FAF7F5

### Typography
- Display Font: Cabinet Grotesk (headlines)
- Body Font: Inter

### Tagline
"Favorites on repeat. New loves on deck. Groceries on autopilot."

### Social Card Content Suggestions
Include:
- Go, Cart! wordmark/logo
- Tagline or key benefit
- High-quality food photography (appetizing, bright, natural lighting)
- Clear visual hierarchy
- Consistent with landing page design

## Optimization Checklist

- [ ] All PNGs optimized with tools like TinyPNG or ImageOptim
- [ ] SVGs minified and optimized
- [ ] WebP versions created for photos/complex images
- [ ] Proper aspect ratios maintained
- [ ] Color profiles embedded (sRGB)
- [ ] Alt text prepared for all images
- [ ] File sizes kept reasonable:
  - Icons: < 5KB each
  - Social cards: < 100KB each
  - Logos: < 10KB each
