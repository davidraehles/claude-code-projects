# Deployment Scripts

Scripts for monitoring and managing Railway deployments.

## Available Scripts

### monitor-railway-deployment.sh
Monitors Railway deployment status and health.
```bash
./scripts/deployment/monitor-railway-deployment.sh
```

### railway-status.sh
Checks current Railway deployment status.
```bash
./scripts/deployment/railway-status.sh
```

## Usage

Run from project root:
```bash
./scripts/deployment/monitor-railway-deployment.sh
```
